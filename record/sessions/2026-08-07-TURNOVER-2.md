## 4. What a fresh session will get wrong

1. **The chat prompts in `round-006-chat/` mirror round 006** — before the pointer and
   before web search. That is deliberate: they are the no-pointer chat baseline. Do not
   "update" them; emit a new round if you want the pointer condition.
2. **`git add -A` in this repo is dangerous.** The loop's commit prefix list is
   enumerated for a reason; adding files to the working tree while a round runs will
   trip its post-commit cleanliness check and cost a paid round its commit.
3. **The context pack pin will refuse** after any change to `record/decisions/` or the
   deficiency table. That is the control working. Re-pin deliberately, in the same
   commit as whatever changed it.
4. **The parties are never pooled.** Routed ≠ chat surface ≠ local, and a tool-using
   local invocation will be a fourth party, not the third one with more powers.

## 5. Next: the shim

Codex cannot drive the local Qwen. Two blockers, both verified against the binary and
the server (`TRT-LLM 1.3.0rc23`):

- recent Codex removed `wire_api = "chat"`, so only `/v1/responses` remains;
- TRT-LLM's `/v1/responses` rejects the canonical typed message item
  (`{"type":"message","content":[{"type":"input_text"…}]}` → *"No user query found in
  messages"*) and refuses `prompt_cache_key` / `client_metadata` as `extra_forbidden`.
  It accepts a plain string and `EasyInputMessage`, and it accepts function tools.

**The defect record is at
`Consullo/deploy/inference-hosts/turing/trtllm-patches/defects/responses-api-input-item-union.md`**
— outside this repo, deliberately. (I first wrote that `trtllm-patches/` did not exist
here; my search was three levels too shallow. It does exist, and it is the canonical
home for TRT-LLM defect records.)

The shim adapts typed items to `EasyInputMessage`, drops the two forbidden fields, and
passes the rest through. **Every transformation it makes must be recorded in the round
artifacts** — a shim we write is only better than a third-party proxy if it is
observable. Design with Codex first.

Scope for the arm it unblocks: `record/designs/qwen-tool-using-arm-scope.md`, with the
custodian's four decisions — read-only **verified by effect before the first sample**,
general web, its own round id (`round-NNN-tools`), and a first run against a question
already asked without tools.
