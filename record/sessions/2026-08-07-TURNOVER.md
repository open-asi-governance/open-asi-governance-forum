## 2. What the loop is

`tools/round_cycle.py` advances the deliberation by **at most one round per
invocation, then exits.** Not a daemon. It selects a question from parties'
own proposals, composes a prompt from a hashed template, solicits k≥5 from five
parties, records, and **commits to a branch — never `main`.**

It deliberately does **not** write a synthesis, resolve a dispute, invent a
question, or adopt anything. Gemini made unilateral synthesis by the conflicted
moderator a condition of **declining to participate**; a loop that wrote findings
would lose that party.

`--selector` is required with no default. `rotation` is adopted — see
`record/decisions/2026-08-07-adopt-rotation.json`, which records that the adoption
**overrode the benchmark's own conclusion** that no mechanism should be adopted on
this evidence.

committed and re-ran on it.** `ast.parse` reported "syntax ok" because the file
was still valid Python — just unmodified. Round 000b's prompt came out
**byte-identical** to round 000's, so a five-party k=5 round re-tested a condition
already measured, and I reported it as a before/after.

Grok caught it before I did, quoting the template verbatim in its answer. I read
that as a model repeating stale framing rather than as a party accurately
reporting what it received.

`compose()` then self-verified on its first run and found a **second, older bug**:
`{answer_space}` had **never** been substituted, in any version, so a literal
`{answer_space}` shipped to ten party invocations across both live rounds.

**This was the fourth fail-silent defect of mine in one day** — a vacuous test, a
"binary" fixture that was valid UTF-8, a substring check defeated by a line wrap,
and this. **The pattern is verifying syntax instead of effect.** Six integrity
cases now test effect: composed size, pack presence, quoted proposer field, and
that a forgotten slot *raises* rather than shipping.

## 5. Codex's review — the priority list, unaddressed

All verified by Codex against the code, none fixed yet. In its order of severity:

1. **`--dry-run` never calls `compose()`** (`round_cycle.py:370`), so the new
   self-checks only run *after* a live round has begun. Its first recommendation:
   make `--dry-run` build and validate every final spec before spending anything.
2. **Sequential `str.replace` corrupts proposer text.** A question containing a
   literal `{answer_space}` gets the answer instructions substituted into it and
   then *passes* the placeholder check. Reproduced for question, reason, and
   `evidence_needed`.
3. **`load_queue()` rebuilds every proposal with `asked=False` every invocation**
   (`agenda_selectors.py:85`); no round record is consulted. **The agenda will
   repeat already-asked questions** — Codex confirmed rotation returns P001 again
   after one party cycle. Persist disposition.
4. **Git failures are ignored** while the tool prints "recorded"
   (`round_cycle.py:474`).
5. **The "fixed" pack is not fixed:** it reads current decisions and the current
   deficiency table, so its bytes change as the repo changes. Codex's better rule:
   each proposal carries an immutable hash-addressed evidence manifest at
   submission; a mechanical resolver includes exactly those plus a small versioned
   core pack; over the ceiling, the proposal is refused rather than trimmed.
6. **Halts don't match the design.** Schema-invalid replies, budget breach and
   provider change are specified and unchecked. Unreadable lifecycle records are
   silently ignored where fail-closed is needed.
7. **Unanimity: halting is defensible, suppressing the record is not.** Unanimous
   "insufficient context" *is* evidence and should be recorded before halting.
   `unanimous()` also compares only the modal category — parties can give
   incompatible substantive answers under one label.
8. **`check_prompt.py`'s sent-prompt carve-out is exploitable:** round specs name
   the reusable template, so future defects in the *live* template become
   non-fatal. It exempts a path, not immutable bytes, and checks markdown rather
   than final composed prompts.
9. **Design drift:** the SOP text adopts the portfolio; the code adopts rotation.
   Reconcile.
